# Local Workbench（本地工作台）

Local Workbench 是一款面向 macOS 的原生任务与专注工作台。它以 SwiftUI 和 AppKit 构建，提供简洁的三栏任务管理界面，将快速捕获、每日规划、番茄专注和本地数据保护集中在一个轻量应用中。

## 功能

- **今日 / 本周 / 待定**：分类管理任务，支持跨列表移动、拖动排序、完成状态和撤销。
- **随时问**：与任务分类同级的入口，二级 tab 为 ChatGPT / DeepSeek / 豆包，点击后在应用内打开对应官方网页版。
- **快速捕获与标签解析**：通过自然的简写输入任务，可设置标签、优先级、估时和计划时间；支持键盘快捷键。
- **任务搜索与编辑**：按标题、说明、标签、时间或笔记搜索，并编辑任务详情。
- **每日规划与专注**：今日概览展示聚焦任务、进度和剩余估时；内置 25/50 分钟专注、短休息、完成记录和收工复盘。
- **备份与恢复**：支持导入、导出 JSON；检测损坏数据并尝试从备份恢复。
- **本地任务**：任务数据保存在用户自己的 macOS 目录，不连接 iCloud，也不读取或修改苹果备忘录；随时问中的登录和对话由对应网站处理。

## 特点

- 纯原生 macOS 界面，无第三方运行时依赖。
- 支持 macOS 14 及以上，并提供 Apple Silicon 与 Intel 构建。
- 专注计时依据实际截止时间计算，Mac 休眠后仍能更新。
- 本地数据采用原子写入与受限文件权限，并对损坏或保存失败提供保护。
- 分类任务保持独立，不会随日期自动搬移。

## 运行

在 Finder 中打开 `dist/本地工作台.app`，或在项目目录执行：

```sh
npm start
```

首次启动时任务列表为空。开发构建需要 Xcode Command Line Tools 提供的 Swift 编译器，不需要安装 npm 依赖：

```sh
npm run doctor
npm run build
```

## 验证

```sh
npm test
npm run test:package-contents
npm run test:all
```

测试会使用独立临时目录，不读写正式任务和登录数据。GUI 验收记录在 `test-results/`。

## 随时问的使用

点击左侧「随时问」（⌘4），再选择 ChatGPT、DeepSeek 或豆包。三个页面首次点击才联网加载，已打开的页面在切换平台或返回任务时保留输入、滚动位置和会话。重启后重新打开网站，由平台恢复账号与聊天记录；尚未发送的网页草稿不保证跨应用重启保留。

网页工具栏提供后退、前进、刷新、平台首页和默认浏览器入口；⌘F 可查找当前网页文字。网页中的 N、P、1/2/3、/ 等输入不会触发任务快捷键。⌘1/2/3 返回任务分类，⌘K 仍可使用全局命令。

三个平台使用独立的持久化 WebKit 数据空间，登录 cookie 与网站存储保存在本机 WebKit 管理的目录中，独立于任务 JSON，也不会自动继承 Safari 的登录。登录弹窗在应用内打开，上传使用系统文件选择器，下载使用系统保存面板（选择尚不存在的文件名）。

随时问使用网页版，不调用平台 API，也不会自动发送本地任务或笔记。可用性取决于本机网络、平台账号以及网站对内嵌浏览器的支持。若平台的验证码或第三方登录不支持内嵌 WebKit，可使用「默认浏览器」入口继续；外部浏览器登录不会自动回传到 app。应用不绕过网站验证或 TLS 检查。

开发 GUI 测试可用 `LOCAL_NOTES_DATA_DIR` 指定独立任务和网页登录空间。`LOCAL_NOTES_WEB_TEST_ORIGIN` 仅接受 `http://127.0.0.1:端口`，用于本机测试页面，不改变正式平台入口。

## 数据位置

默认数据位于 `~/Library/Application Support/LocalNotes/workbench.json`。应用没有云同步功能，建议使用内置导出功能自行备份。

## 项目结构

- `Sources/`：任务逻辑、存储、应用状态与 SwiftUI 界面。
- `Tests/`：核心逻辑测试。
- `Resources/`：应用资源和 macOS 配置。
- `scripts/`：构建、测试、打包和诊断脚本。
- `功能对照.md`：项目功能对照记录。
